# 演示 GIF 录制说明

README 顶部引用的是 `docs/demo.gif`，按下面的流程录制即可。

## 建议录制的流程（10–15 秒）

1. 打开一篇库外笔记（Ribbon →「打开库外文件」）
2. 粘贴一张截图，展示它自动保存到 `External Vault/attachments`
3. 展示编辑器里生成的相对路径（如 `../External Vault/attachments/xxx.png`）
4. 右键标签页 →「移入 Vault」
5. 打开库内笔记，展示附件已跟随、链接正常显示

## 录制与转换（macOS）

1. 打开 QuickTime Player → 文件 → 新建屏幕录制，录制上述流程
2. 停止后导出为 `demo.mov`
3. 转成 GIF（需要安装 ffmpeg：`brew install ffmpeg`）：

```bash
ffmpeg -i demo.mov \
  -vf "fps=12,scale=900:-1:flags=lanczos" \
  -loop 0 docs/demo.gif
```

4. 把 `docs/demo.gif` 提交到仓库，README 会自动显示

## 体积控制

- 宽度 900px、12fps，10 秒左右通常在 1–2 MB
- 如果超过 5 MB，可以降到 720px / 10fps，或只截取关键片段
